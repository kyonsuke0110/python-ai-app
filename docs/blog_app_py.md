# StreamlitでAIツールの「ホーム画面」を作る — `app.py`解説

## この記事について

これは、Python + Streamlit + Gemini APIで作った個人用AIライティングツールの、いちばん最初に読み込まれるファイル `app.py` の解説記事です。全体でたった35行ですが、Streamlitアプリの「顔」となる部分を担っています。

## 1. 必要な部品を読み込む

```python
import streamlit as st
from common.ui import setup_page
```

Streamlit本体に加えて、`common/ui.py`から`setup_page`という自作の関数を読み込んでいます。これは「サイドバーのAPIキー入力欄を表示する」「ページタイトルを設定する」といった、**全ページ共通の処理をまとめた関数**です。各ページで同じコードを書かずに済むように、共通処理は`common/`フォルダに切り出してあります。

## 2. ページの初期設定

```python
setup_page("AIライティングツール", "🖋️")
```

たった1行ですが、この裏では「ブラウザタブのタイトルとアイコンを設定」「サイドバーにAPIキー・モデル選択欄を描画」「ページの見出し（`# 🖋️ AIライティングツール`）を表示」という3つの処理が走っています。すべてのページの先頭でこの関数を呼ぶことで、見た目と設定の一貫性を保っています。

## 3. 説明文を表示する

```python
st.write(
    "ブログ執筆・メール返信・要約など、複数のライティング支援AIを"
    "ひとつにまとめた個人用ツールです。左のサイドバーからGemini APIキーを設定し、"
    "使いたい機能のページを開いてください。"
)
```

`st.write()`はStreamlitの「なんでも表示できる」関数です。長い日本語文字列を3行に分けて書いていますが、Pythonでは隣り合う文字列リテラルが自動的に連結されるので、実行時には1つの文章として表示されます。

## 4. 機能一覧をデータとして定義する

ここがこのファイルの核心部分です。

```python
features = [
    ("pages/1_📝_ブログ記事作成.py", "📝", "ブログ記事作成", "テーマから見出し付きのブログ記事の下書きを生成します。"),
    ("pages/2_📧_メール返信.py", "📧", "メール返信作成", "受信メールと返信の要点から、返信文案を作成します。"),
    # ...以下7機能分続く
]
```

各機能を「ページのパス・アイコン・名前・説明文」という4要素のタプルとして、リストにまとめています。**表示ロジックとデータを分離**しているのがポイントです。もし機能を追加したくなったら、下の描画ループを触らずに、このリストに1行足すだけで済みます（実際には`pages/`フォルダに新しいファイルを作る必要もありますが）。

## 5. カード形式で一覧を描画する

```python
cols = st.columns(2)
for i, (page, icon, name, desc) in enumerate(features):
    with cols[i % 2]:
        with st.container(border=True):
            st.subheader(f"{icon} {name}")
            st.caption(desc)
            st.page_link(page, label=f"{name}を開く", icon=icon)
```

少し複雑に見えるので分解します。

- `st.columns(2)` — 画面を左右2列に分割し、それぞれの列オブジェクトを`cols`に格納
- `enumerate(features)` — リストの中身を「インデックス番号, 要素」の組で取り出せるようにする
- `i % 2` — インデックスを2で割った余り（0か1）を使って、**偶数番目は左列、奇数番目は右列**に交互に振り分けるテクニック
- `st.container(border=True)` — 枠線付きの箱を作り、その中に見出し・説明・リンクをまとめて「カードUI」に見せている
- `st.page_link(page, ...)` — クリックすると指定したページファイルに遷移するリンクボタン。Streamlitのマルチページ機能ならではの部品

タプルの4要素を`for page, icon, name, desc in ...`のように一気に分解して受け取れるのも、Pythonのアンパック代入の便利なところです。

## 6. 締めのメッセージ

```python
st.divider()
st.caption("個人用ツールのため、ログイン機能やデータベースは実装していません。生成内容はブラウザセッション内にのみ保持されます。")
```

`st.divider()`で区切り線を引き、`st.caption()`で小さめのグレーな注釈テキストを表示。ユーザー（＝あなた自身）に、このツールの前提（DB・認証なし、データは残らない）をさりげなく伝えています。

## まとめ

`app.py`がやっているのは、実は**「共通処理を呼ぶ」「文言を並べる」「データからUIを組み立てる」の3つだけ**です。実際にAIを呼び出す複雑なロジックは各`pages/*.py`と`common/gemini_client.py`側にあり、`app.py`はあくまで「ホーム画面の見た目を組み立てる係」に徹しています。この役割分担が、Streamlitアプリをシンプルに保つコツです。
